# 嵌入式 C 代码审查

对嵌入式 C 代码进行全面的安全和质量审查：

1. **获取更改的文件**：
   ```bash
   git diff --name-only HEAD
   ```

2. **嵌入式 C 特定检查项**：

   **安全性（关键）：**
   - 缓冲区溢出
   - 整数溢出
   - 未初始化变量使用
   - 竞态条件（中断上下文）
   - 硬件访问错误

   **硬件交互（高优先级）：**
   - volatile 关键字使用
   - 寄存器访问安全性
   - 内存对齐
   - 位操作正确性

   **实时性能（高优先级）：**
   - 阻塞操作（中断中）
   - 动态内存分配
   - 浮点运算（无 FPU）
   - 不确定延迟

   **内存管理（中优先级）：**
   - 内存泄漏
   - 双重释放
   - 栈溢出风险

   **代码质量（中优先级）：**
   - 函数 > 50 行
   - magic numbers
   - 缺少注释（硬件操作）

3. **报告格式**：
   - 严重程度：CRITICAL, HIGH, MEDIUM, LOW
   - 文件位置和行号
   - 问题描述
   - 建议修复

4. **阻止提交条件**：
   - 发现 CRITICAL 或 HIGH 问题时阻止

使用 `agent: embedded-c-reviewer` 进行详细审查。
