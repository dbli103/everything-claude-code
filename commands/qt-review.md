# Qt C++ 代码审查

对 Qt C++ 代码进行全面的安全和质量审查：

1. **获取更改的文件**：
   ```bash
   git diff --name-only HEAD
   ```

2. **Qt C++ 特定检查项**：

   **安全性（关键）：**
   - 内存泄漏（未管理的 QObject 子树）
   - 空指针解引用
   - 缓冲区溢出风险
   - 资源未释放

   **Qt 特定模式（高优先级）：**
   - 信号槽连接类型（新式 vs 旧式）
   - Lambda 捕获安全性
   - Q_OBJECT 宏使用
   - 线程亲和性（跨线程信号槽）
   - UI 线程阻塞

   **代码质量（中优先级）：**
   - 函数 > 50 行
   - 文件 > 800 行
   - 嵌套深度 > 4 层
   - 缺少错误处理

   **性能（中等）：**
   - 隐式共享误用
   - 不必要的拷贝
   - 大对象通过值传递

3. **报告格式**：
   - 严重程度：CRITICAL, HIGH, MEDIUM, LOW
   - 文件位置和行号
   - 问题描述
   - 建议修复

4. **阻止提交条件**：
   - 发现 CRITICAL 或 HIGH 问题时阻止

使用 `agent: qt-cpp-reviewer` 进行详细审查。
